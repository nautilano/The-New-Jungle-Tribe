Connected

"Even with all the evil and crazyness of the world. I can't help but to appreciate the one family we are. Yes, we are one, but we are one crazy mind. So don't think everything is solved or they will understand. We are on disadvantage here. The path is clear, but the view is not. Still so much to unfold. We are all brothers, but some have been hurt in the soul. So this is to be taken lightly. With medicinal eyes and honoring codes. The ones to recover, the ones never to be lost. And here we all go, and some will see and some will not. Some will help each other, some will fall in a hole. And then we'll see we have been dragged, slowed down, by the ones we ignore. When we are up, some will follow. Like a sunny day after a while, after so much rain and the darkest clouds. Then we see it's all back again. A slight normality, a well deserved balance. The one we forgot there was. That we are all together in this. The same big bowl. The same mistake, the same big joy.  I realize when I walk and see them all, you my dear people, worry no more. Step by step we will get there at some point."
