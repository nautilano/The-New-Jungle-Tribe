Loves show

Love is a long road. It goes across time, across generations. So be sure you will never run from it. It will get you, as it gets to all of us. There’s just some ignoring, some fighting it. The ones who later realize their true cause of their problems. But never think love can be stored or blocked. Be aware of its true power. No secret and no fear can stop it from spreading. It may take some time, it may take some lives. But love is wise and unstoppable. So just be ready to witness all the ways it finds to be spoken. To be shown. To be expressed. Be ready for the show and make sure not to interrupt it. You have the choice there to either  run or fly. Love wants you to fly.
